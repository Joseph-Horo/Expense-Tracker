
<h1 align="center" id="title">Expense Tracker</h1>

<p id="description">An Expense Tracker application built with Kotlin and Jetpack Compose that allows users to manage and track their expenses. Built using MVVM Multi-module Architecture Dagger Hilt for dependency injection Room for local data persistence and Firebase Authentication for user authentication.</p>
